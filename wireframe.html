import numpy as np
def k_means(X, k=3, max_iter=20, seed=0):
rng = np.random.default_rng(seed)
centroids = X[rng.choice(len(X), k, replace=False)]
yield {"type": "init", "centroids": centroids.tolist()}
for it in range(max_iter):
# Assign each point to nearest centroid
dists = np.linalg.norm(X[:, None] - centroids, axis=2)
labels = dists.argmin(axis=1)
yield {"type": "assign", "iteration": it, ...}
# Recompute centroids as cluster means
centroids = np.array([X[labels==j].mean(0) for j in range(k)])

About this algorithm Unsupervised

K-Means partitions data into k clusters by iteratively assigning points to the nearest centroid and recomputing centroids as cluster means.

Time
O(n·k·d·i)
Space
O(n·d + k·d)
✓ Spherical, similarly-sized clusters
✓ Fast on medium datasets
✗ Non-convex shapes (try moons!)
✗ Sensitive to initialization & k
